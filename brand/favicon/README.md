# Favicon

- `icon.svg` is the source: a cream "C" on palm green (#1E7A55) with a sun-orange (#FF8A3D) dot. It's drawn with shapes rather than text, so it stays crisp at 16px.
- The site uses three copies:
  - `src/app/icon.svg`, for modern browsers;
  - `src/app/favicon.ico` (16, 32 and 48px), for everything else;
  - `src/app/apple-icon.png`, the 180px home-screen icon (Chuk's face in the orange ring, matching the header logo, from `brand/chuk/chuk-head.png`).
- `icon-192.png` and `icon-512.png` are for anywhere else that needs a PNG, such as a Google Business profile or a web manifest.
