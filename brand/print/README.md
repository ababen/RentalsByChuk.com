# Print kit

Business card, flyer, tri-fold brochure and brand style guide for RentalsByChuk.

**Live, editable canvas:** https://claude.ai/artifact/2QemP64oqU2h2EMXSh58dF (private until shared from its Share menu; export print PDFs from there).

Tagline: **Your next rental, and move, handled.**

| Piece | Size | Preview |
| --- | --- | --- |
| Business card (front / back) | 3.5 × 2 in | `preview/business-card-front.html`, `preview/business-card-back.html` |
| Flyer | 8.5 × 11 in | `preview/flyer.html` |
| Tri-fold brochure (outside / inside) | 11 × 8.5 in, letter fold | `preview/brochure-outside.html`, `preview/brochure-inside.html` |
| Brand style guide | Letter, flowing | `preview/style-guide.html` |

- `preview/` — standalone HTML; open in a browser. Images load from `brand/chuk/`.
- `source/` — the canvas's original `.dc.html` artboards and `canvas.json`.
- `qr-rentalsbychuk.svg` — QR code to https://rentalsbychuk.com (navy on white).

Every piece carries the agent name, LoKation Real Estate, FL Lic. SL3596634 and Equal Housing Opportunity, and avoids "free"/fee claims and fair-housing red flags (see the style guide's Compliance section).
